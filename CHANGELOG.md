# Changelog

## 0.1.0 — Initial preview

- Native Windows reader for CBZ/ZIP and nested image folders.
- Natural page ordering, manga navigation, fit/zoom, and focus mode.
- Local library with reading progress, bookmarks, and backup recovery.
- Speech-bubble selection, local Tesseract OCR, and offline CPU neural translation.
- Editable text, model-aware caching, saved translation notes, and export.
- Cancellable background work, image/archive limits, and corrupt-page handling.
- Original demo, automated regression/UI checks, and portable Windows publishing.

This preview integrates existing OCR and translation models. It does not provide
automatic bubble detection, CBR/PDF support, replacement lettering, a signed
installer, or measured translation accuracy across a manga corpus.
